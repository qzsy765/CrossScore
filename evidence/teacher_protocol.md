## 二、V1.2新教师前瞻训练协议（训练开始前确定）
| 项目 | 不可事后更改的值 |
|---|---|
| 教师架构 | CIFAR-ResNet50（与旧权重可strict-load的同一结构）|
| ID数据 | CIFAR-10、CIFAR-100各训练一位教师，分别运行在10153、10302 RTX4090 |
| 数据划分 | CIFAR官方50,000张train=True；固定seed=20261020，45,000 train/5,000 ID validation，沿用B2 V1.0数据划分哈希 |
| 官方测试集 | 教师训练程序完全禁止加载train=False、OID数据，或据其改变任何训练超参数及checkpoint |
| 教师固定随机种子 | 20261020（两任务复现性一致；训练各自模型） |
| 初始化 | 随机初始化，不复用旧教师权重；记录初始权重哈希 |
| 预处理 | 与B2 V1.0学生训练协议一致：RandomCrop(32,padding=4)、RandomHorizontalFlip、Normalize(CIFAR均值/标准差)，确定性sample+epoch增强 |
| 优化器 | SGD，lr=0.1, momentum=0.9, weight_decay=0.0005，非Nesterov |
| 学习率 | 5轮线性预热，从0.01×目标lr到1×；余下195轮余弦退火；总200轮 |
| Batch Size | 128；全训练+全ID验证集，各epoch评估 |
| 训练目标 | 仅ID Cross-Entropy；不使用OOD正则、辅助头、RFKD或SCG-AC |
| 主教师定义 | **Epoch200最终权重**，训练前即锁定；不按验证集选择，5k仅监测学习曲线，防止教师选择与学生ID验证双重使用 |
| 辅助checkpoint | best-ID-val（仅审计与对照展示，不替代主教师） |
| 断点恢复 | 每epoch原子保存学生/教师权重、优化器、scheduler、Python/NumPy/CPU/CUDA RNG、训练/验证曲线、源码与manifest SHA；唯一任务锁与GPU忙碌保护 |
| 硬件 | 两台分别一项任务，任一GPU已被占用或共享数据/指纹不一致则不启动；无需额外算力授权 |
| 模型评估 | 完成200轮后锁定新教师SHA，首先报告ID验证表现，再由独立评估器使用官方ID测试集及六OOD集；其结果不得反向调参 |
| 意外失败 | 原样保留负结果和原因，绝不以较优中间轮次代替事先预定Epoch200 |
| 论文披露 | 既有旧教师及五月历史实验只属Legacy；V1.2是真正独立的新确认性数据链，不能宣称旧论文实验被事后修正 |

## 三、V1.2学生协议承继与必要变更
- CIFAR-10、CIFAR-100×五学生配对种子101/202/303/404/505×四方法CE/VanillaKD_T4/CrossScore_LegacyAsCode/CrossScore_T6_Corrected，共40组学生200轮与六OOD评估，主要 AUROC、次要 FPR95/AUPR/ID准确率不变。
- **变更仅在教师来源**：旧 `teacher_baseline.pth` 替换为V1.2分别锁定的epoch200教师。因教师更换是实质性科研变更，另立 `student_manifest_V1.2`，不在V1.0清单上直接改写教师SHA256。
- 原始T标签历史问题仍保持诚实：LegacyAsCode不接入教师温度；修正版明确T=6。FPR95并列阈值口径按V1.1执行，不能回写历史值。
- 学生ID验证使用同一预留的5k训练集子集。与教师第200轮固定输出配对，教师不使用5k选择主权重，降低模型选择链路相关性。
- 学生40组派发之前：V1.2教师checkpoint必须二者都严格加载、SHA冻结、200轮DONE可核验；重新审核公平配对、任务锁/磁盘/代码哈希，再单独写放行事件。
